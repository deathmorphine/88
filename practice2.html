Мета роботи

Навчитися використовувати каскадні таблиці стилів (CSS) для оформлення HTML-сторінок, зокрема форми реєстрації з лабораторної роботи №1.

У цій роботі застосовано кольори фону та тексту, ширину, внутрішні відступи, закруглені кути, тіні, позиціювання й плавні переходи.

Форма реєстрації зі стилізацією CSS

Нижче — оформлена форма з лабораторної №1. Поля позначені зірочкою (*) — обов'язкові.

Увага: для перевірки надсилання використовуйте лише вигадані дані та тестовий пароль. Форма надсилає дані до навчального сервісу Webhook.site.

Використані можливості CSS

  • Колір фону й тексту: background, background-color, color.
  • Ширина та відступи: width, max-width, padding, margin.
  • Закруглені кути: border-radius.
  • Рамки й тіні: border, box-shadow.
  • Позиціювання: position, top, z-index.
  • Переходи та ефекти: transition, transform, :hover, :focus.
  • Адаптивність: медіазапит @media для невеликих екранів.

Висновок

У ході практичної роботи №2 було оформлено форму реєстрації за допомогою зовнішнього CSS-файлу style.css. Додано кольори, відступи, рамки, закруглення, тіні, позиціювання та плавні переходи при взаємодії з елементами.
